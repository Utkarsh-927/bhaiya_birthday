BHAI BIRTHDAY — CINEMATIC BROTHERHOOD WEBSITE

Open index.html in a browser. The uploaded photos are stored in /assets and are used directly; no generated people or stock photos are included.

Files:
- index.html
- styles.css
- script.js
- assets/*.jpeg

Features:
- Responsive desktop/tablet/mobile layout
- Smooth scrolling and chapter progress
- Scroll reveal animations
- Cinematic hero and "KING" portrait section
- Then/Now comparison
- Photo gallery with lightbox
- Optional user-triggered ambient soundtrack (no autoplay)
- Replay button
- Reduced-motion support

For best results, open index.html in Chrome/Edge/Firefox. The Google Fonts connection is optional; the site has serif/sans fallbacks if offline.
